private signed

Sign an embed URL, in your own browser.

Private embed borrows a login you already have. Signed embed manufactures one — and manufacturing it needs your instance's embed secret, which is why this mode normally costs you a server.

There is no server here. The signing runs in Python, in a background thread of this tab. Watch the log: your secret goes into a worker on this page and never leaves it. Confirm that in the network tab.

Use a throwaway or rotatable secret. Anyone holding an embed secret can mint a URL as any user with any permission. This page is the safest possible place to paste one — it is your own browser — but the habit is worth keeping.

You need Admin → Platform → Embed: an embed secret, and SSO embedding enabled. The model name is the LookML model the dashboard reads from; the signed user gets access to that model and nothing else.

Then add this origin to the Embedded Domain Allowlist. Unlike private embed, signed embed is checked against it — and the browser checks the whole ancestor chain, so a page holding this page needs listing too.
